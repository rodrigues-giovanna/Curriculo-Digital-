# 💻 Humor do Programador

Um projeto simples e divertido desenvolvido com **HTML, CSS e JavaScript**. O cartão muda de humor sempre que o botão é pressionado, alterando o emoji, a mensagem e as cores do tema em um estilo inspirado em programação.

# ✨ Funcionalidades

* 🎭 5 humores diferentes do programador
* 🌈 Mudança de cores a cada clique
* 💬 Mensagens temáticas sobre programação
* ⚡ Interface inspirada em um terminal

## 🛠️ Tecnologias utilizadas

* HTML
* CSS
* JavaScript
